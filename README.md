# Проектная работа "Умная таблица"

## :grey_question: Описание проекта
Страница "Умная таблица" отображает данные в наглядном виде и позволяет их отфильтровать.

## :mag_right: Стек:
- HTML
- CSS
- JavaScript
- Vite

## :file_folder: Структура проекта
1. `.github/workflows/` - каталог с файлами тестов и настройками деплоя на GitHub.
2. `public/` - каталог с картинками.
3. `src/` - каталог с логикой и стилями.
6. `.gitignore` - файл для запуска программы.
7. `.README.md` - файл описания проекта.
8. `index.html` - файл разметки страницы.
9. `package-lock.json` - файл блокировки зависимостей.
10. `package.json` - файл с информацией о зависимостях.
11. `vite.config.js` - файл конфигурации сборщика.
